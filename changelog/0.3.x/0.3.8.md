# 0.3.8 — 2026-10-13

## Added

- **`indexed_nutriments` on `off_search_products` rows** (#58) — a search with `nutrient_filters` returns the text index's values for the constrained nutrients, keyed like `off_get_product` (`sugars_100g`). They can differ from the current record.
- **`page_size` and `page_size_capped` on `off_search_products`** (#57) — report the page size served and whether the request was cut to it.
- **`unprocessed` on `off_compare_products`** (#57) — barcodes past the 10th distinct one, listed without being fetched.

## Changed

- **Over-cap reads are served bounded instead of rejected** (#57) — `off_search_products` accepts `page_size` up to 10000 and serves 50 (`page` counts pages of 50); `off_compare_products` accepts up to 100 `barcodes` and fetches 10; `off_browse_taxonomy` accepts `limit` up to 200 and returns 100, naming how many matched.
- **`off_search_products` text queries treat `_`, in-word `'` / `’` / `.`, and decimal commas as part of a word** (#50) — `milk-chocolate`, `milk/chocolate`, and `lait 1,5%` now require each part.
- **`off_compare_products` compares a repeated barcode once** — two identical barcodes yield one row.
- **Nutrition is labeled per 100 g, or per 100 ml for liquids** (#51) — across tool descriptions, output descriptions, and the table headings; values are unchanged, and a record with only per-serving values gets no per-100 heading.
- **`off_get_product` labels open-map nutrients with the unit of the nutrient itself** (#52), not its `_unit` sibling.
- **`off_compare_products` row labels escape brand text** (#56) — a row is `name (brand)`, `Barcode N (brand)`, or `Barcode N`.
- **Final result pages no longer carry `truncated`, `shown`, or `cap`** (#55) — `truncated` now means more results lie beyond the page.

## Fixed

- **A 2xx body missing its result fields fails as the retryable `upstream_error`** (#54) — instead of reading as a product `not_found`, a zero-match search, or a tag with no match. In `off_compare_products` it lists in `failed`; in `off_browse_taxonomy` it takes the noticed offline fallback.
- **A non-JSON 2xx body fails as `upstream_error`** (#61), not a reason-less `ValidationError`.
- **Taxonomy lookups end as cancelled when the caller aborts** (#60), instead of degrading to `lookup_failed` or the offline sample.
