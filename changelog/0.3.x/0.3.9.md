# 0.3.9 — 2026-10-25

## Changed

- **Product text** uses the framework's Markdown escaper across lookup, search, comparison tables, and taxonomy output, preserving literal entities, tildes, pipes, and ordinary underscores.
- **Product images** render as Markdown images for absolute HTTP(S) URLs; unsupported or malformed destinations remain literal text.
- **Maintenance** syncs framework guidance and audit classification, trims development files from MCPB bundles, documents request-state sealing, and gives client-specific hosted connection examples.
- **Runtime tests** load the config dependency graph during collection and shorten CPU sampling batches while retaining five samples, the input-size span, and growth thresholds.
